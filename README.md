# Dating HQ CRM v4 PWA

This is the upgraded installable mobile CRM.

Included:
- Dashboard opens first
- Cover photo for every profile
- Multiple image attachments/screenshots
- Timeline for each person
- Drag-and-drop pipeline
- Follow-up queue
- Travel relevance
- Search
- Message templates
- Offline cache
- iPhone home-screen icon
- Full JSON export/import backup

## Install on iPhone
The app must be hosted over HTTPS.
1. Upload the contents of this folder to Netlify, Cloudflare Pages, GitHub Pages or Vercel.
2. Open the hosted address in Safari.
3. Tap Share.
4. Tap Add to Home Screen.

## Limitation
This build stores everything locally in the browser. Secure cross-device sync, login, AI reply generation, push notifications and automatic ChatGPT integration require a hosted backend and API credentials.
